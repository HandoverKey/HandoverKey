## What is HandoverKey?

HandoverKey is a self-hostable, open-source **digital legacy platform**. You store encrypted secrets in a zero-knowledge vault. If you stop checking in, a dead man's switch kicks off a handover flow — delivering cryptographic key shares to the trusted successors you chose. Decryption happens in their browser. The server never sees plaintext.
